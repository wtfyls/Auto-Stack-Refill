# Auto Stack Refill

A small Minecraft Forge mod that automatically refills your selected hotbar slot with a matching stack from your inventory when the stack in that slot runs out.

## Features
- Refills an emptied selected hotbar slot from your inventory.
- Matches the item and its data/components, so differently enchanted or customized items are not mixed.
- Works server-side, including on dedicated servers.
- Lightweight: no configuration required.

## Compatibility
- Minecraft **1.20.1**
- Minecraft Forge **47.4.28** (built against Forge 1.20.1)

## Building
Requires Java 17.

```bash
gradle build
```

The built mod jar will be in `build/libs/`.
