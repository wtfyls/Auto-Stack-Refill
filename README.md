<p>Auto Stack Refill moves another matching stack from your inventory into the selected hotbar slot when the stack you're holding runs out.</p>

<p>It checks that the item matches, including its item data, so it doesn't refill the slot with a different variant by mistake.</p>

<h3>Install</h3>
<ol>
  <li>Use Minecraft 1.20.1 with a supported loader.</li>
  <li>Download the file for your loader from <a href="https://www.curseforge.com/minecraft/mc-mods/auto-stack-refill">CurseForge</a>.</li>
  <li>Put the jar in your <code>mods</code> folder and launch the game.</li>
</ol>
